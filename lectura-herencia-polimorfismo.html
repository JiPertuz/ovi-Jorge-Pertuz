Herencia y polimorfismo

Cómo una clase extiende a otra y cómo cambia su comportamiento.

La herencia permite que una clase hija reutilice los atributos y métodos de su clase padre. El polimorfismo hace que una misma llamada produzca resultados distintos según el objeto que la reciba.

public class Animal {
    public String sonido() { return "..."; }
}

public class Perro extends Animal {
    @Override
    public String sonido() { return "Guau"; }
}

Animal a = new Perro();
a.sonido(); // "Guau"
