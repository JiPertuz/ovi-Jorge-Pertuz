Clases y objetos

El molde y las instancias que se crean a partir de él.

Una clase es el molde; un objeto es una instancia creada a partir de ese molde. El encapsulamiento se logra con atributos privados y métodos de acceso. Según explica IBM "la programación orientada a objetos se basa en el concepto de crear un modelo del problema de destino en sus programas según la documentación de MDN Web Docs (2024), las clases funcionan como plantillas para crear objetos, encapsulando los datos junto con el código que opera sobre ellos."

public class Estudiante {
    private String nombre;

    public Estudiante(String nombre) { this.nombre = nombre; }
    public String getNombre() { return nombre; }
}

Estudiante e = new Estudiante("Ana");

Elementos de una clase

  • Atributos: los datos del objeto.
  • Constructor: inicializa el objeto al crearlo.
  • Métodos: las acciones que el objeto puede realizar.
